# TeaStore adapter

Kieker/AspectJ method-level posture. The first new validation target is
adaptive method-signature activation under none/full/selected configurations.

Logical selections are compiled through `activation/catalog.json`. The catalog
closes selections over mandatory activation groups; it currently records that
TeaStore's manual registry-client propagation cannot be disabled independently
inside the pinned published images. Performance claims require validated,
matched none/selected/full receipts rather than telemetry counts alone.
