## Rules

- Entry point: `research/hotel-selected/ledger_check.py` rule, unchanged. Requests started in [fault applied, fault reverting] vs before; shows = any failed in-window request, or in-window median > pre-window median + max(3 x MAD, 1 ms). Hotel calls `ledger_check.cell`; TeaStore applies the same lines to every request of `journey-ledger.jsonl` (window = intervention actualOnset/OffsetMonotonicOffsetSeconds, barrier-relative like the ledger; ok = `succeeded` and 200); OTel to `request-ledger.json` (window = intervention offsets + ledger startedAtEpoch; ok = 200 and no error).
- Sensors outside the target: each population's own detector, G2 (the faulted service's sensors excluded) and G3. Own: the same detector with G2 inverted (only the target's sensors), G3 kept. Families: L log templates (and their rate subsensors on TeaStore/earlier corpus), M container CPU (docker stats), Mm container memory (earlier corpus only), S cgroup system sampler (Hotel lmt2/sel1/int1 only), Tsel spans under `selected`, T spans under `full` (`kieker-native` on the earlier corpus).
- A family's n is the row's episodes whose posture collects it. Per-posture columns count an episode as caught when any family collected in that posture catches it outside the target.
- visibilityClass (majority: a column catches when 2k > n): entry-visible if the entry point catches; else interior-only-outside if any family catches outside the target; else own-service-only if any family catches on the target's own sensors; else unseen. `—` where the entry point was not recorded. visibilityClassAnyEpisode repeats it with k >= 1.
- C/Csel (int1 catalogue spans) are subsets of T/Tsel; reported in the JSON, never used in the derivation.
