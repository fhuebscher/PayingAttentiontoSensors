## Defaults and limits

Every engineering default is in the docstring of `project_map.py` and in `project_map.json` → `defaults`. Main limits: one cell per posture (n = 1, so `o` is a single-run absence, not a property); call-site counts are lower bounds (no vendor/library code; Go struct-field loggers unresolved); Kotlin, Python, Node, .NET, C++, Ruby, PHP, Rust sources are not parsed (`configured-level-only`); the role vocabulary is a fixed table of server products; TeaStore's registry has no spans, so 'off route' there means 'not on a traced route'.
