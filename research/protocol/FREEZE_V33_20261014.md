- The TeaStore epoch is read as campaign-B shaped (H4 freeze stamps). If its cells carry another record key set the run stops (UnknownSchema): a stop, not a guess.
- The recommender's affected path is `{recommender}`; registry spikes are not counted by the path filter (registry *log* fires are not spikes and are unaffected).
- Lane (b) is every log id of `kafka` / `registry` (a rule by service, not by message text), a superset of the group-coordinator / heartbeat-removal lines.
- BC-flagged fires are not counted (celf_v3's rule) and are reported beside the counted field as `earliestByConstruction`; the own lane of E reads 0 counted, 3 of 3
  by construction.
- Kafka lag metrics are admitted only when the resource carries `service.name=kafka`; a resource without it is dropped by the adapter. `MIN_BASELINE_POOLED` stays 20.
